PIANO PLAY LAB 1.6 - F3 TO F5 TOY PIANO

1. Unzip and open the PianoPlay_Phase2A folder.
2. Double-click START_WINDOWS.bat (Windows) or run a localhost static server.
3. Open http://localhost:8000 in Chrome.
4. Click/tap the leftmost F3 key to confirm on-screen interaction.
5. Start listening, allow microphone access, and play the physical leftmost key.
6. It should sound near 174.61 Hz if F3 is correct.
7. The fifth white key is C4 (261.63 Hz). Optional calibration: capture F3, then C4.
8. Finish a lesson for chimes, score, restart/next.

KEY RANGE: F3 to F5, 25 keys total (15 white, 10 black). No hardware buttons shown.
ANDROID: host on GitHub Pages over HTTPS and use Chrome.

See README.md and CHANGELOG_v1.6.md for notes.
