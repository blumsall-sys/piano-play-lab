# v2.0 — 20 Lessons and Chords

- Expanded from 9 to 20 editable beginner lessons.
- Introduced multi-note lesson events, using note arrays for chords.
- Preserved exact F3–F5 25-key keyboard from the previous release.
- Added green visual progress for keys already collected in a chord.
- Updated note prompts and voice instructions to describe multi-key exercises.
- Added simultaneous chord audio playback to the Hear whole melody demo.
- Added recommended microphone Build chord practice and experimental Together mode.
- Added USB MIDI note-on/off support for hardware that supports MIDI, requiring chord notes held together.
- Adjusted scoring to count individual note/key presses for chords; displayed ideal presses vs actual.
- Added simulated chord-detector diagnostic and synthetic FFT tests.
- Embedded and synchronized all 20 lessons in `index.html` to avoid stale-lesson loading.
- Updated package version/cache-busting, docs and tests.

LIMITATION: Polyphonic microphone recognition is experimental and was not verified on the user's physical piano or Android tablet. For the pictured toy piano use microphone Build chord mode, or on-screen tapping.
