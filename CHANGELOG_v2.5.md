# v2.5 — Three-Try Rhythm Highway

Added three-try timed practice with one 4/4 bar of empty beats between each loop. The highway now visibly plays the melody or chord sequence again and the target key selection resets before the next attempt. Each attempt is scored separately, with early completion on an accurate performance or a results screen after three tries. A repeat toggle allows single-pass mode. All previous keyboard, audio, settings and curriculum functionality remains in the same package.

See `REPEAT_CHALLENGE_v2.5.md` for controls, scoring and setup.
