- Retains the original 20 lesson IDs and data for saved progress compatibility.
- Adds 30 new lessons with finger-number practice, simple theory, rhythm, recognizable traditional/public-domain songs and coordinated two-hand exercises.
- Uses `lessons/lessons.json` as the **primary** live lesson catalog. Later lesson additions can be deployed by editing that file alone.
- Adds a validated embedded 50-lesson backup and a visible warning if live JSON is stale or malformed.
- Keeps the existing Learn/Perform Rhythm Highway, 3-try loop, microphone, MIDI and Settings.
- Adds optional `handGuide` and `handAssignments` metadata shown near the Rhythm Highway and beneath notes when space permits.
- Expands the lesson map to 50 cards, keeps the same 70% unlock progression, and preserves old progress keys.
- Updates testing, source docs and version/cache labels.

Physical Hape microphone recognition, USB MIDI and Android speech still require testing on the target hardware.
